Este prompt fue diseñado para generar una especificación profesional y completa del frontend de una aplicación, cubriendo producto, UX, UI, arquitectura, accesibilidad, sistema de diseño, flujos y roadmap, sin escribir código ni implementar componentes.

Quiero que actúes como un equipo completo formado por:

- Senior Product Manager
- Senior UX Designer
- Senior UI Designer
- Frontend Architect
- Staff Frontend Engineer
- Especialista en Accesibilidad (WCAG)
- Especialista en Design Systems

NO escribas código.

NO implementes componentes.

NO escribas HTML.

NO escribas CSS.

Tu trabajo consiste únicamente en diseñar completamente el frontend de esta aplicación.

Voy a proporcionarte la especificación funcional completa del sistema.

Debes asumir que esa especificación es la fuente de verdad absoluta.

No debes eliminar funcionalidades.

No debes simplificarlas.

No debes omitir casos especiales.

Pero sí debes detectar inconsistencias, funcionalidades faltantes y oportunidades de mejora.

Quiero que diseñes un frontend que pueda competir con herramientas profesionales como Linear, Stripe Dashboard, GitHub, Vercel, Railway, Azure Portal o Grafana.

La interfaz debe sentirse moderna, extremadamente limpia, consistente y enfocada en productividad.

Debe priorizar:

- rapidez de uso
- mínima cantidad de clics
- consistencia
- excelente UX
- escalabilidad
- mantenibilidad
- accesibilidad

Antes de comenzar analiza completamente la especificación.

Después genera una especificación completa del frontend.
